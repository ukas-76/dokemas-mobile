BAB II
Manual Book Aplikasi DOKEMAS

2.1 Pengenalan Aplikasi

DOKEMAS (Dolan Keliling Banyumas) adalah aplikasi mobile berbasis Flutter yang dirancang untuk membantu masyarakat dan wisatawan dalam menemukan, merencanakan, dan menikmati destinasi wisata di wilayah Banyumas. Aplikasi terhubung secara real-time dengan backend Laravel melalui REST API yang aman menggunakan token Sanctum.

2.2 Persyaratan Sistem

ItemKebutuhan
Sistem OperasiAndroid 6.0 (API 23) ke atas / iOS 12 ke atas
Koneksi InternetDiperlukan untuk mengambil data destinasi & gambar dari server
AkunDiperlukan untuk fitur Wishlist, Itinerary, dan Review

2.3 Struktur Navigasi & Peran Pengguna

Aplikasi memiliki dua alur utama berdasarkan peran pengguna:

PeranAlur MasukFitur yang Tersedia
Tamu (Guest) Splash → Main Screen (tanpa login) Beranda, Explore, baca Detail Destinasi
User Splash → Login → Main Screen Semua fitur tamu + Wishlist, Itinerary, tulis Review, Profil
Admin Splash → Login → Admin Panel Dashboard statistik + CRUD Destinasi, Kategori, Fasilitas, User, Moderasi Review

2.5 Panduan Penggunaan Per Fitur

2.5.1 Splash Screen & Deteksi Login Otomatis

Saat aplikasi pertama kali dibuka, layar splash screen akan tampil selama ±2 detik menampilkan logo DOKEMAS. Pada saat yang sama, aplikasi secara otomatis memeriksa token login yang tersimpan di perangkat.

Alur Otomatis:
  • Token ditemukan & role = admin → diarahkan ke Admin Panel
  • Token ditemukan & role = user → diarahkan ke Beranda
  • Tidak ada token → masuk ke Beranda sebagai tamu (Guest)

2.5.2 Registrasi Akun Baru

Pengguna baru dapat membuat akun melalui halaman Register yang diakses dari halaman Login.

Langkah-langkah:
  • Buka aplikasi → tap "Belum punya akun? Daftar" di halaman Login
  • Isi formulir: Nama Lengkap, Email, Password, Konfirmasi Password
  • Tap tombol "Daftar" — sistem mengirim data ke server
  • Jika berhasil, pengguna otomatis diarahkan ke halaman Beranda
  • Jika gagal (mis. email sudah terdaftar), muncul pesan error di layar

2.5.3 Login

Pengguna yang sudah memiliki akun dapat masuk menggunakan email dan password.

Langkah-langkah:
  • Buka aplikasi → tap ikon profil di header, atau tab "Profil" di navigasi bawah
  • Masukkan Email dan Password
  • Tap "Masuk" — loading indicator tampil saat proses
  • Berhasil: token tersimpan → masuk ke Beranda (user) atau Admin Panel (admin)
  • Gagal: pesan kesalahan ditampilkan di layar

2.5.4 Lupa Password (Reset via OTP)

Fitur reset password menggunakan kode One-Time Password (OTP) yang dikirimkan ke email terdaftar.

Langkah-langkah:
  • Di halaman Login → tap "Lupa Password?"
  • Masukkan email yang terdaftar → tap "Kirim OTP"
  • Buka inbox email → salin kode OTP 6 digit yang diterima
  • Masukkan kode OTP di halaman verifikasi → tap "Verifikasi"
  • Masukkan password baru dan konfirmasinya → tap "Reset Password"
  • Password berhasil diperbarui → diarahkan kembali ke halaman Login

2.5.5 Beranda (Home)

Halaman Beranda adalah tampilan utama yang menyajikan destinasi populer dan kategori wisata. Data diambil secara real-time dari API.

Tombol "Lihat Semua"Membuka halaman Explore dengan seluruh daftar destinasi

2.5.6 Halaman Explore

Explore menampilkan seluruh destinasi dengan pencarian lanjutan dan filter multi-kriteria.

Cara Menggunakan Filter:
  • Tap ikon filter di sebelah kanan search bar untuk membuka panel filter
  • Pilih Kategori: Semua / Alam / Kuliner / Keluarga / Edukasi / Religi
  • Pilih Rentang Harga: Gratis, < Rp 50.000, Rp 50.000–100.000, dsb.
  • Pilih Rating Minimum: ≥ 4.0, ≥ 4.5, dsb.
  • Pilih Fasilitas yang diinginkan (Parkir, Toilet, WiFi, dll.) — multi-pilih
  • Tap "Terapkan Filter" untuk memperbarui hasil pencarian
  • Tap "Reset" untuk menghapus semua filter sekaligus

2.5.8 Wishlist / Favorit

Fitur Wishlist memungkinkan pengguna menyimpan destinasi yang ingin dikunjungi. Fitur ini hanya tersedia bagi pengguna yang sudah login.

Cara Menggunakan:
  • Di halaman Detail Destinasi → tap ikon hati (♥) di pojok kanan atas
  • Ikon berubah menjadi hati terisi; destinasi masuk ke daftar Wishlist
  • Buka tab "Wishlist" di navigasi bawah untuk melihat semua favorit
  • Gunakan search bar di halaman Wishlist untuk mencari destinasi tertentu
  • Hapus: tap ikon hapus (×) pada kartu, atau toggle kembali ikon hati di halaman Detail

2.5.9 Itinerary (Rencana Perjalanan)

Itinerary membantu pengguna membuat jadwal perjalanan wisata yang terstruktur. Fitur ini hanya tersedia bagi pengguna yang sudah login.

Cara Membuat Itinerary Baru:
  • Buka tab "Itinerary" di navigasi bawah
  • Tap tombol "+ Buat Itinerary"
  • Isi judul (mis. "Liburan ke Baturraden") dan pilih tanggal mulai & selesai
  • Tap "Simpan" — itinerary baru muncul di daftar
Cara Menambahkan Destinasi ke Itinerary:
  • Buka halaman Detail Destinasi → tap "Tambah ke Itinerary"
  • Pilih itinerary yang diinginkan dari dialog yang muncul
  • Destinasi langsung masuk ke timeline itinerary yang dipilih
Cara Mengelola Itinerary:
  • Tap nama itinerary untuk membuka detail; destinasi ditampilkan dalam format timeline
  • Tap ikon edit ✎ untuk mengubah judul atau tanggal itinerary
  • Tap ikon hapus pada item untuk menghapus satu destinasi dari itinerary
  • Tap tombol hapus itinerary untuk menghapus seluruh itinerary beserta isinya

2.5.11 Panel Admin

Panel Admin hanya dapat diakses oleh akun berperan admin. Panel ini menyediakan pengelolaan konten aplikasi secara penuh melalui bottom navigation bar dengan 5 tab utama.

Tab 1 – Dashboard

Menampilkan ringkasan statistik aplikasi secara keseluruhan.

InformasiKeterangan
Total DestinasiJumlah keseluruhan destinasi yang terdaftar di sistem
Total UserJumlah akun pengguna yang terdaftar
Total ReviewJumlah seluruh ulasan yang masuk dari pengguna
Top RatingDaftar destinasi dengan nilai rating tertinggi

FAB (Floating Action Button) di Dashboard bersifat speed-dial: tap untuk memunculkan menu cepat tambah User, Kategori, Fasilitas, dan Destinasi sekaligus.

Tab 2 – Destinasi

Mengelola seluruh data destinasi wisata (CRUD — Create, Read, Update, Delete).

Cara Menambah Destinasi:
  • Tap tombol "+" atau FAB di tab Destinasi
  • Isi: Nama, Kategori, Deskripsi, Harga, Jam Buka, Lokasi, Jarak
  • Upload thumbnail (foto utama) dan galeri foto (multi)
  • Centang fasilitas yang tersedia → tap "Simpan"
  • Foto dikonversi otomatis ke format WebP di server
Cara Mengedit / Menghapus Destinasi:
  • Cari destinasi → tap kartu untuk membuka opsi
  • Tap ✎ untuk mengedit data, atau 🗑 untuk menghapus destinasi
  • Konfirmasi dialog hapus → destinasi dihapus dari sistem beserta foto-fotonya

Tab 3 – Kelola (Kategori, Fasilitas, User)

Sub-MenuFungsi
Kelola KategoriTambah, edit, hapus kategori wisata (mis. Alam, Kuliner, Religi, dll.)
Kelola FasilitasTambah, edit, hapus fasilitas (mis. Parkir, Toilet, WiFi, Musala)
Kelola UserLihat daftar pengguna, ubah data, atau hapus akun pengguna

Tab 4 – Review

Halaman moderasi ulasan pengguna. Admin dapat melihat seluruh review dari semua destinasi dan menghapus ulasan yang tidak sesuai dengan kebijakan aplikasi.

Tab 5 – Profil Admin

Sama dengan profil user biasa: edit data diri, ganti password, dan logout dari panel admin.

Penutup

3.1 Kesimpulan

Aplikasi DOKEMAS (Dolan Keliling Banyumas) berhasil dikembangkan sebagai solusi digital untuk promosi dan navigasi pariwisata daerah Banyumas. Dengan mengintegrasikan teknologi Flutter pada sisi mobile dan Laravel 13 pada sisi backend, aplikasi mampu menyajikan informasi destinasi wisata secara real-time, lengkap dengan fitur perencanaan perjalanan (itinerary), manajemen favorit (wishlist), sistem ulasan pengguna, serta panel administrasi yang komprehensif.

Setiap anggota kelompok telah memberikan kontribusi nyata sesuai pembagian tugas yang disepakati, mulai dari pengembangan backend API, desain antarmuka pengguna, integrasi fitur, hingga pengujian aplikasi secara menyeluruh.
